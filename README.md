# hxyfront-62003 法医昆虫学样本发育进度台账

在原“法医昆虫学样本记录”静态样例基础上补成的发育进度台账。

## 功能

- **批次台账**：每批样本记录采样地点、昆虫种类、保存方式、案件关联、鉴定备注；每条温度记录包含采样时间、环境温度、温度持续时间（日）。
- **有效积温计算**（`src/lib/thermal.ts`，纯函数）：
  - 发育起点 10℃，每条记录按 `max(0, 温度 - 10) × 持续日数` 累加；
  - 累计 ≥ 20 日·度进入幼虫，≥ 45 进入蛹，≥ 80 进入成虫；
  - 同时给出每段有效温度、平均温度、距下一阶段所需积温。
- **温度改正**：记录可就地编辑（时间/温度/持续时间）或删除，保存后累计积温、判定阶段、发育曲线立即一起重算。
- **发育进度曲线**（SVG）：横轴为发育日数，纵轴为累计有效积温；含 20/45/80 阈值虚线、卵/幼虫/蛹/成虫阶段色带与逐段阶梯折线。
- **阶段筛选**：全部 / 卵 / 幼虫 / 蛹 / 成虫，只过滤批次列表，不改数据；列表带各阶段计数。
- **联动详情**：批次列表选中后，详情卡片、案件关联、鉴定备注、温度记录、曲线全部随所选批次切换；备注可编辑并保存。
- **本地持久化**（`src/lib/storage.ts`）：数据写入 `localStorage`，关闭页面再打开仍是原记录；首次打开载入三条样例批次。

## 分层维护

| 关注点 | 位置 |

| 页面操作与组件 | `src/App.tsx`、`src/components/*` |
