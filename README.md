# hxyfront-62003 法医昆虫学样本记录

源提示词编号：5

做一个法医昆虫学样本记录前端工具，用来记录采样地点、环境温度、尸体暴露阶段、昆虫种类、发育阶段、采样时间、保存方式和鉴定备注。页面需要有样本批次列表、发育阶段筛选、温度记录图、案件样本关联页和单个样本详情卡片。

## 技术栈

React + Vite + TypeScript

## 功能

- 发育进度台账：每批样本记录采样时间、环境温度、持续时间，按高于 10℃ 部分累加有效积温（度·日）
- 阶段阈值：20 度·日进入幼虫，45 进入蛹，80 进入成虫
- 温度录错可直接在表格中修改，阶段判定与积温曲线实时重算
- 发育阶段筛选、案件关联批次、鉴定备注均跟随当前选中批次
- 数据持久化在 localStorage，关掉页面再打开记录不丢失

## 代码结构

- `src/domain/` — 积温计算（发育起点温度、阈值、阶段判定），纯函数
- `src/store/` — 温度记录与批次状态、localStorage 持久化
- `src/components/` — 页面操作与展示（批次列表、详情卡片、积温曲线、录入表单）

## 本地运行

```bash
npm install
npm run dev
```
